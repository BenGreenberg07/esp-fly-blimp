Slow-down distance: cruise is rolled off linearly over the last N metres before the arrive ring, so it is already coasting when it gets there instead of driving in at full power and overshooting (it can't brake). Raise it if it still overshoots; the pill shows live cruise %.
Push: two independent triggers, whichever fires first — a shove (sharp speed, this is what tells a real push apart from slow air drift) or a slower carry past the distance. Lower the speed if pushes aren't registering; raise it if its own drift keeps re-triggering.
arriveR is both the "we're there" radius here AND the radius the firmware flashes the LED inside. Slower cruise = tighter arcs = it can reach points closer to a wall.
